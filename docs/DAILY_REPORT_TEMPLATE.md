## 텔레그램 출력 규칙

- HTML parse_mode 사용. 항목당 3줄 (제목 / 마감·지역·형태 / 링크).
- 마감 임박 전부 + 신규 상위 15건. 초과분은 "외 n건 → 전체 보기 링크".
- 4,096자 초과 시 섹션 경계에서 메시지 분할.
- 이모지는 섹션 헤더에만 사용.

## 이메일 출력 규칙

- 제목: `[경남 강사공고] 09/21 신규 7 · 마감임박 3`
- 본문: 위 Markdown을 HTML로 변환. 표는 기본 스타일, 링크는 절대 URL.
- 발신자 이름: `경남 강사공고 알림`.

## 정렬 규칙

1. 마감 임박: 마감 시각 오름차순.
2. 신규: `관심 가중치(field) × 관련성 점수` 내림차순 → 마감 가까운 순 → 기관 유형 순(local_gov, edu_office, local_public, central_public, university, private).
3. 변경: 변경 감지 시각 내림차순.
